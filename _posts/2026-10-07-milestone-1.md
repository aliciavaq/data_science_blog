## Question 1

To download all NHL play-by-play data for the regular-season and playoff games from 2016-2017 season to 2023-2024 season, we used two functions.

<b> 1. get_season_game_ids(year) </b>

This first function retrieves the IDs of all regular-season and playoff games for a given NHL season. Each ID represents a unique identifier that can then be used to retrieve its play-by-play data from the NHL API.

The first step is to define the date range for the season. The <b> start_date </b> is September 1st of the given year and the <b> end_date </b> is October 31th of the following year. We chose this range because the NHL season generally begins in October and ends in June, including the playoffs. There was some exceptions, and the season 2019-2020 is a good example because the playoffs ended on September 28th, 2020. This date range therefore provides some extra time before and after the expected season. 

We initialize an empty set called <b> game_ids </b> to store the game IDs for the selected season. A set  only keeps unique values, which is useful because the NHL API returns schedules organized by game weeks, and since we advance through the calendar one week at a time, we want to make sure that we do not store the same ID twice.

We then initialize <b> current_date </b> with <b> start_date </b>, which determines the date used for the first API request. We use the NHL schedule-by-date endpoint (documented in the NHL API reference https://github.com/Zmalski/NHL-API-Reference#get-schedule-by-date) to retrieve the schedules associated with that date, using the URL <b> "https://api-web.nhle.com/v1/schedule/"f"{current_date.isoformat()}" </b>. The isoformat() method converts the date into the YYYY-MM-DD format required by the URL. 

The API response contains a <b> gameWeek </b> field, which groups games by week, so we can iterate though each week and then through each games listed for that week. For every game, we retrieve its ID and check 3 conditions : 1. "gameType" must be 2 (regular-season games) or 3 (playoff games) to exclude other game types. 2. The game ID must not be missing (for example, if there is no games during a week, we do not want to retrieve "empty" data). 3. The game ID must start with the starting year provided to the function to ensure that we do not get the data from the next or previous season (since the end_date is september 28th, it could be overlapping with the start of the next season). If all 3 conditions are met, the game ID is added to the set. 

After each request, we advance <b> current_date </b> by 7 days, and until <b> current_date <= end_date </b>. Once the <b> end_date </b> has been reached, the function returns the game IDs as a sorted list.

We also use print statements to display the season that we are retrieving the data from, and to display the number of games found.


<b> 2. get_hockey_data(year, path=None) </b>

Once we have the game IDs, the second function retrieves the play-by-play data for each game and combines the events into a pandas DataFrame.

The first step is to define the directory where the data will be stored. We can either provide a directory directly through the path argument or use the HOCKEY_DATA_DIR environment variable. If neither is provided, the function raises an error.

We then create a subfolder for the selected season, if it does not already exist, to organize the raw JSON files by season.

Next, we call the first function, <b> get_season_game_ids(year) </b>, to obtain the game IDs for the selected season. We create an empty list called <b> all_plays </b> to store the play-by-play DataFrames, then we iterate through the game IDs returned by the first function. For each game, we define the path of its JSON file using the game ID as the filename (example : a game with ID 2016010001 would be stored in a file named 2016010001.json).

Before making an API request, the function checks if the JSON file for that game already exists in the specified directory. If the file exists, its contents are loaded directly into Python to avoid downloading the same data again. If the file does not exist, the function downloads the play-by-play data from the NHL API using the URL <b> "https://api-web.nhle.com/v1/gamecenter/"f"{game_id}/play-by-play" </b>. We then convert the JSON response into a Python dictionary.

Before saving the data, we verify that the ID in the returned data matches the requested game iD and we check that the plays field exists and contains a list. After validating the response, we save the complete JSON data to the specified directory.

Next, we convert the game's events into a pandas DataFrame, and add a <b> game_id </b> column to identify the game associated with each event. This is important because the final dataset combines events from many different games.

Each game's DataFrame is appended to <b> all_plays </b>. Once all the game IDs have been processed, we concatenate the individual DataFrames into one large DataFrame. Each row represents an event and the columns contain the information associated with that event.

We also added a 1 second pause between each request with <b> time.sleep(1) </b> to reduce the frequency of API requests and avoid sending too many requests in a short period.

Additionally, print statements display a progress message after every 100 games and when the last game has been processed.

Since the second function calls the first function internally, we only need to call <b> get_hockey_data() </b> to retrieve the play-by-play data for a season.

# Load the data for the selected season 

def load_season_games(year):

    season = f"{year}-{str(year + 1)[-2:]}"
    season_dir = DATA_DIR / season

    if not season_dir.exists():
        raise FileNotFoundError(
            f"The directory {season_dir} does not exist."
        )

    # Dictionary that stores the games 
    games = {}
    # Loop through all JSON files in the season folder
    for file_path in sorted(season_dir.glob("*.json")):

        with file_path.open("r", encoding="utf-8") as file:
            game_data = json.load(file)

        game_id = game_data.get("id")

        if game_id is None:
            game_id = int(file_path.stem)

        game_id = int(game_id)

        # 02 = regular season, 03 = playoffs
        game_type = str(game_id)[4:6]

        if game_type not in ("02", "03"):
            continue
            
        # Get list of the events from the game 
        plays = game_data.get("plays", [])

        if isinstance(plays, list):
            games[game_id] = {
                "game_id": game_id,
                "game_type": game_type,
                "plays": plays,
                "metadata": game_data
            }
    # Error if no games were found 
    if not games:
        raise ValueError(
            f"No games were found in {season_dir}."
        )

    return games
# Get the coordinates for the diffferent events 

def get_coordinates(play):

    details = play.get("details", {})

    if not isinstance(details, dict):
        details = {}

    x = details.get("xCoord")
    y = details.get("yCoord")

    try:
        if x is not None and y is not None:
            return float(x), float(y)
    except (TypeError, ValueError):
        pass

    return None, None

# Display the different events and the statistics of the selected game 

def display_event(game_id, event_index):

    game = current_games[game_id]
    plays = game["plays"]
    metadata = game["metadata"]
   
    # Clear the different outputs before displaying new information 
    with output:
        clear_output(wait=True)

        if not plays:
            print("No events available.")
            return

        event_index = min(
            max(event_index, 0),
            len(plays) - 1
        )
        # Get the selected events 
        play = plays[event_index]

        # Getting the information for the different teams 
        home = metadata.get("homeTeam", {})
        away = metadata.get("awayTeam", {})
        
        #Get the name abbreviation and ID of each teams 
        home_name = home.get("abbrev", "Home")
        away_name = away.get("abbrev", "Away")

        home_id = home.get("id")
        away_id = away.get("id")

        print(
            f"Game ID: {game_id}; "
            f"{home_name} (home) vs {away_name} (away)"
        )

        # Calculate the different goals and shot on goals 
        # Initialize the statistics 
        home_goals = 0
        away_goals = 0
        home_sog = 0
        away_sog = 0
        
        # Loop through all the events in the game 
        for p in plays:

            event_type = (
                p.get("typeDescKey")
                or p.get("typeDesc")
                or ""
            ).lower()

            details_p = p.get("details", {})

            if not isinstance(details_p, dict):
                details_p = {}

            team_id = details_p.get("eventOwnerTeamId")

            # Count the goals and the shot on goals 
            if event_type in ("goal", "shot-on-goal"):

                if team_id == home_id:
                    home_sog += 1
                elif team_id == away_id:
                    away_sog += 1

            if event_type == "goal":

                if team_id == home_id:
                    home_goals += 1
                elif team_id == away_id:
                    away_goals += 1

        # Extracting the different periods in the game 
        period_info = play.get("periodDescriptor", {})

        if not isinstance(period_info, dict):
            period_info = {}
            
        # Get the period number and type
        period_number = period_info.get("number", "?")
        period_type = period_info.get("periodType", "")

        if period_type == "OT":
            period_label = "OT"
        elif period_type == "SO":
            period_label = "Shootout"
        else:
            period_label = f"Period {period_number}"

        # Display both teams statistics and the period 
        print(f"\n{period_label}")
        print(f"{'':15s} {'Home':12s} Away")
        print(f"{'Teams:':15s} {home_name:12s} {away_name}")
        print(f"{'Goals:':15s} {home_goals:<12} {away_goals}")
        print(
            f"{'Shots on goal:':15s} "
            f"{home_sog:<12} {away_sog}"
        )

        # Create the title for the event 
        event_type = (
            play.get("typeDescKey")
            or play.get("typeDesc")
            or "Unknown event"
        )

        title = event_type.replace("-", " ").capitalize()
        time_in_period = play.get("timeInPeriod", "?")
        # Display the event number, title and the time 
        print(f"\nEvent {event_index + 1}/{len(plays)}")
        print(title)
        print(f"{time_in_period} — {period_label}")

        # Display the ice rink 
        # Get the coordinates 
        x, y = get_coordinates(play)

        if rink is not None:

            fig, ax = plt.subplots(figsize=(12, 5))

            ax.imshow(
                rink,
                extent=(-100, 100, -42.5, 42.5),
                origin="lower",
                aspect="auto"
            )

            # Mark the event with a blue circle if coordinates are available 
            if x is not None and y is not None:

                ax.scatter(
                    x,
                    y,
                    color="blue",
                    s=120,
                    edgecolors="white",
                    linewidths=1.5,
                    zorder=5
                )

            else:
                print(
                    "\nNo coordinates are available "
                    "for this event."
                )

            ax.set_xlim(-100, 100)
            ax.set_ylim(-42.5, 42.5)
            ax.set_xlabel("Feet")
            ax.set_ylabel("Feet")

            ax.set_title(
                f"{title}\n"
                f"{time_in_period} — {period_label}"
            )

            plt.show()
            plt.close(fig)

        else:
            print("Ice rink image not found.")

        # Display the events data 
        print("\nEvent data:")
        print(json.dumps(play, indent=2, ensure_ascii=False))
# Update the game list based on the selected season 
def update_games(change=None):

    global current_games
    
    # Load all the games from the selected season 
    try:
        current_games = load_season_games(
            season_widget.value
        )

        selected_type = type_widget.value

        matching_games = sorted([
            game_id
            for game_id, game in current_games.items()
            if game["game_type"] == selected_type
        ])
    
        if not matching_games:

            game_widget.options = []

            with output:
                clear_output(wait=True)
                print("No games are available for this game type.")

            return

        game_widget.options = [
            (str(game_id), game_id)
            for game_id in matching_games
        ]
        # atomatically selects the first game in the list 
        game_widget.value = matching_games[0]

    except Exception as error:

        with output:
            clear_output(wait=True)
            print("Error:", error)
# Update the event slider when a different game is selected 
def update_event_slider(change=None):

    if game_widget.value is None:
        return

    game_id = game_widget.value
    plays = current_games[game_id]["plays"]

    event_widget.max = max(len(plays) - 1, 0)
    event_widget.value = 0
    # Display the forst event of the selected game 
    display_event(game_id, 0)

#Update the displayed event when the slider value changes
def update_display(change=None):

    if game_widget.value is not None:
        display_event(
            game_widget.value,
            event_widget.value
        )
# Connect the widgets 
season_widget.observe(update_games, names="value")
type_widget.observe(update_games, names="value")
game_widget.observe(update_event_slider, names="value")
event_widget.observe(update_display, names="value")
